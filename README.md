## 🏗️ Brazilian E-Commerce Data Warehouse — Olist
📌 Overview

This project focuses on the design and implementation of an end-to-end Data Warehouse using the Brazilian E-Commerce public dataset provided by Olist.

The main objective is to transform raw e-commerce data into a structured, reliable and analytics-ready data platform following a Medallion Architecture.

The project covers the different stages of a typical data pipeline:

Raw Data → Bronze → Silver → Gold → Data Warehouse → Analytics

The project was designed as a practical exercise to strengthen my skills in:

Data Warehouse architecture
ETL / ELT processes
SQL and PostgreSQL
Data modeling
Data transformation
Data quality
Surrogate keys
Slowly Changing Dimensions (SCD)
Query optimization
Business-oriented data analysis
🎯 Project Objectives

The main objectives of this project are to:

Design a scalable Data Warehouse architecture.
Implement a Medallion Architecture.
Build an ETL pipeline using SQL.
Clean and standardize raw data.
Create dimension and fact tables.
Implement surrogate keys.
Apply data quality and validation rules.
Prepare data for analytical queries and BI tools.
Practice dimensional modeling.
Understand how technical decisions can support business requirements.
📊 Dataset

The project uses the Brazilian E-Commerce Public Dataset by Olist, available on Kaggle.

🔗 Dataset: https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce
